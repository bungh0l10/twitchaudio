# Twitch Audio Plugin for Lyrion Music Server

Play Twitch live streams and VODs as audio on LMS. No Twitch account required.

Add this URL under **Settings > Plugins > Additional Repositories**:

```text
https://raw.githubusercontent.com/bungh0l10/twitchaudio/main/repo/repo.xml
```

Install **Twitch**, restart LMS and open **Apps > Twitch**.
